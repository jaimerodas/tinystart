Browsers

Chrome extension

The extension shows your start page in each new Chrome tab.

  1. Download the extension
  2. Unzip the downloaded file.
  3. Open chrome://extensions and turn on Developer mode.
  4. Click "Load unpacked" and select the unzipped folder.

Safari

Safari can open your start page in each new window and tab. It needs no extension.

  1. In Safari, choose Safari > Settings, then click General.
  2. Set Homepage to {{.Data.URL}}.
  3. Set both "New windows open with" and "New tabs open with" to Homepage.
